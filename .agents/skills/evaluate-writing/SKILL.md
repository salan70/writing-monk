# Evaluate writing

## Procedure

1. Determine the context.
2. Load the active profile and relevant accepted preferences.
3. Evaluate the draft against each applicable preference.
4. Mark each as:
   - pass
   - partial
   - fail
   - not-applicable
5. Explain failures with concrete excerpts or structural evidence.
6. Distinguish profile violations from ordinary editorial suggestions.
7. Do not modify preferences during evaluation.

## Useful aggregate signals

- applicable preference count
- violation count
- strong violation count
- likely human-edit hotspots
