# MVP scope

## Included

- local case storage
- event-stream history
- Markdown writing artifacts
- human feedback and human-edit events
- semantic-diff schema
- observation schema
- preference candidates
- confidence and counter-evidence
- context-scoped preferences
- generated writing profiles
- profile versioning
- agent skills for generation, analysis, evolution, and evaluation
- JSON Schema contracts
- CLI for case creation, validation, profile generation, and basic stats
- public-repository-safe workspace separation

## Deferred

- Web UI
- vector database
- embeddings
- direct LLM API integration
- hosted database
- automatic accepted-preference mutation
- remote synchronization of personal workspace data

## Completion criterion

The MVP is successful when a second writing task can use a writing profile that was derived from evidence collected during earlier writing/review cases.
