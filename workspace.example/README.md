# workspace

Copy or rename this directory to `workspace/` for local operation.

`workspace/` is intentionally ignored by Git because it contains personal writing data.

Recommended structure:

```text
workspace/
├── cases/
├── preferences/
│   ├── global/
│   ├── technical-writing/
│   ├── teaching/
│   ├── presentation/
│   └── github/
├── profile/
└── reports/
```
